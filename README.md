# Рынок угля Казахстана

Верифицированный аналитический модуль. В основном контуре только показатели с источником, периодом и ссылкой.

## Запуск

```bash
npm install
npm run dev
```

## Правило данных

Если показатель не подтверждён официальной публикацией, интерфейс показывает «Нет подтвержденных данных». Демонстрационные ряды в основной аналитике не используются.
